### 1. Amazon Elastic Cloud (EC2) ⏱️ 9:45-10:45

- **Mô tả**:
  - Tìm hiểu về Amazon Compare Cloud (EC2)
  - Dịch vụ EBS (Elastic Block Storage)
- **Kết quả**:
  - EC2 (Elastic Compute Cloud) là một dịch vụ máy chủ ảo (virtual server) chạy trong môi trường điện toán đám mây của AWS.
  - EC2 được cấu hình theo Instance Type
  - Các yếu tố quyết định máy chủ ảo EC2 : CPU/GPU, Memory, NetWork, Storage
  - EBS cung cấp lưu trữ dạng khối
  - Hiểu được tính năng: Instace Type,AMI,Backup,KeyPair
  - Sử dụng tính năng AMI để tạo ra 1 hoặc nhiều EC2 Instace cùng lúc
  - Tạo backup bằng cách sử dụng tính năng Snapshot
  - Key Pair (public key và private key) dùng để mã hóa thông tin đăng nhập trên EC2 Instace
  - Cách kết nối khác nhau giữa máy chủ Window ,Linux
  - Tính năng Instance Strore là vùng đĩa NVME tốc độ cực cao, nằm trên physical Node
  - Tính năng UserData là đoạn scrip khi tạo EC2 Instace trong IAM
  - Tính năng MetaData là các thông tin liên quan tới EC2 Instace (Ví dụ : Địa chỉ IP Private, HostName,...)
  - MetaData để thực hiện các công việc bằng cách tự động hóa khi lấy thông tin máy chủ từ bên ngoài
  - EC2 Auto Scalling là tính năng hỗ trợ tăng giảm số lượng EC2 Instance dựa trên các điều kiện cụ thể (Scalling Policy)
  - Pricing Options:Gồm có 4 mức giá (On-demand,Reserved Instace,Saving Plant,Spot Instance)
- **Tools/Tech**:
  - Youtube, Github, AWS Console
- **Links**:
  - [EC2 Console](https://ap-southeast-1.console.aws.amazon.com/ec2/home?region=ap-southeast-1#Overview:)
  - [GitHub Organization](https://github.com/AWS-First-Cloud-Journey)
  - [Instance Type](https://aws.amazon.com/vi/ec2/instance-types/?ncl=h_ls)
  - [Instace Store](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/InstanceStorage.html)

### 3. Amazon EFS/FSX ⏱️ 13:00-14:00

- **Mô tả**:
  - Tìm hiểu dịch vụ Amazon EFS/FSx
- **Kết quả**:
  - Hiểu được EFS(Elastic File System) cho phép tạo các NFSv4 Network volume và gán vào nhiều EC2 Instace cùng lúc(Chỉ hỗ trợ trên Linux)
  - Hiểu được FSx cho phép tạo các NTFS volume và gán vào nhiều EC2 Instace cùng lúc sử dụng giao thức SMB( Server Mesage Block), FSx hỗ trợ trên cả Windows và Linux
  - EFS/FSx Tính phí theo dung lượng cấp phát
- **Tools/Tech**:
  - Youtube, Github, AWS Console
- **Links**:
  - [AWS EFS](https://aws.amazon.com/vi/efs/)
  - [AWS FSx](https://aws.amazon.com/vi/fsx/)

### 4. Amazon Application Migration Service (MGN) ⏱️ 14:00-15:00

- **Mô tả**:
  - Tìm hiểu dịch vụ Amazon Application Migration Service (MGN)
- **Kết quả**:
  - MGN dùng để migrate và replicate phục vụ mục đích xây dựng Disaster Recovery Site cho các máy chủ thực, ảo trên AWS
  - Liên tục sao chếp các máy chủ nguồn sang EC2 Instace trên tài khoản AWS (asynchronous/synchronous)
  - Khi thực hiện cut-over MGN sẽ tự động tạo và chạy các máy chủ EC2 trên AWS
- **Tools/Tech**:
  - Youtube, Github, AWS Console
- **Links**:
  - [AWS MGN](https://aws.amazon.com/vi/application-migration-service/)
